# Assignments

Practice exercises that exercise the framework end to end. They are kept verbatim from the
original `docs/assignment/` folder.

- [Assignment 1](assignment-1.md) — set up a project, build a Bootstrap header/footer, a
  static home page and a backend `services` module.
- [Assignment 2 — page widget assignment](assignment-2-page-widget-assignment.md) —
  page and widget assignment exercise.

Use [Getting started](../getting-started/index.md) and the [Guides](../guides/index.md)
while working through them.
